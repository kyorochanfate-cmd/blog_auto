# About ページ用 Markdown

これをはてなブログの **管理画面 → 固定ページ → 新規作成** に貼り付けてください。
URL は `/about` がおすすめ (例: `https://tako-karamaru.hatenablog.com/about`)。

ヘッダー/フッターのナビにこのページへのリンクを追加すると、Google からのサイト評価でも加点されます。

# このブログについて

たこちゃん、今日もガジェットに絡まる ── 最先端テクノロジーとガジェットを「ワクワクする目線」で深掘りするブログです。

## 運営者プロフィール

**運営者**: たこちゃん (Threads: [@takochan_gadget](https://www.threads.net/@takochan_gadget))

学生時代からガジェットを追いかけ続け、社会人になってからは仕事の合間に新製品レビュー・業界動向の分析・先端技術の解説を書き貯めてきました。スマートフォン・PC・AR/VR デバイス・人型ロボット・AI 搭載デバイスといった「物理世界に作用するテクノロジー」が特に好きで、スペック比較や速報だけでなく **「これが普及したら世界はどう変わるか」** という未来の視点で記事を書くことを大切にしています。

## このブログの方針

「Google で検索したら出てくるテンプレ記事」を増やすつもりはありません。代わりに以下を意識しています。

### 1. ワクワクする題材を選ぶ
- 人型ロボット・AR グラス・BCI (脳-コンピュータ接続)・量子コンピューティング・バイオミメティクスなど **「未来を感じさせるテクノロジー」** を優先
- 単なる「○○が値上げ」「○○が発売」では終わらせず、**目撃した興奮を友達に語る温度感** で書く

### 2. 体験記事と「観察者の記事」を明確に区別する
- 実機を所有していない製品は「気になっている」「公式発表によると」のような未所有者の立場で書く
- 体験を装った表現は使わない (E-E-A-T の Trustworthiness を重視)

### 3. 引用と画像のポリシー
- 製品画像はメーカー公式サイトからの引用 (出典明記) または Wikimedia Commons の自由利用可能ライセンス画像のみ使用
- 報道写真は最低限の引用に留め、本文は必ず自分の言葉で書き直す
- 数値・スペック・固有名詞は一次情報 (メーカー公式・公的機関・業界統計) に基づく

### 4. アフィリエイトの開示
- 一部の記事には Amazon アソシエイト・楽天アフィリエイトのリンクが含まれます
- 該当記事の冒頭に「※本記事には広告が含まれます。」と明記しています
- 商品の紹介内容は広告報酬の有無で変えていません

## 専門領域 (得意ジャンル)

- **スマートフォン・モバイルデバイス** — iPhone / Galaxy / Pixel / Xperia の比較分析と購入判断
- **AR/VR・ウェアラブル** — XREAL / Meta / Apple Vision など空間コンピューティング系
- **人型ロボット・身体性 AI** — Boston Dynamics Atlas / Figure / Optimus 等の動向追跡
- **AI 搭載デバイス** — Gemini / Apple Intelligence / Microsoft Copilot 系の実装解説
- **ガジェット周辺** — 充電器・モバイルバッテリー・ノートPC・ヘッドホン・キーボードのスペック深掘り

## ✅ 設置後にやること

1. **このページへのリンクをサイドバーまたはフッターに追加** — はてなブログ「カスタマイズ → サイドバー → モジュール追加 → リンク」で「このブログについて」リンクを追加
2. **記事末尾のフッターに `[このブログについて](/about)` を1行追加** (任意・推奨) — はてなブログ「記事下フッター」設定からHTML追加
3. **Search Console で URL を直接送信** — `https://tako-karamaru.hatenablog.com/about` をクロール依頼してインデックスを促す
